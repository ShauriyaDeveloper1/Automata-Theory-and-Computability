How Subset Construction Works in Plain English (Viva Ready)
1. The Core Idea

An NFA can branch into multiple states at once. A DFA can only be in one state. The algorithm bundles multiple NFA states into single "combo states" (e.g. State B represents {q0, q1}).

2. Union of Branches

To find where a combo state goes on symbol '0', we take everywhere its member states can go in the NFA, and combine them together (Union).

3. Final State Rule

If a DFA combo contains at least one NFA final state, that DFA state automatically becomes an Accepting State (marked with double circles)!

4. Dead / Trap State (∅)

If an NFA state has no arrow for an input symbol, the DFA creates an absorbing Dead State (∅) to ensure every state has a complete deterministic answer.
